# 论文页面检查

以当年适用模板和用户要求确定格式。templates/paper_layout.json 只提供可选起点，不设固定页数、摘要字数或首页填充比例。

- 摘要说明任务、各问关键方法、主要数值与必要验证/限制；保留最有信息的结果，不靠背景凑字数。摘要是否跨页及首页布局需看实际 PDF。
- 每个实际子问题形成“任务→数学定义→求解→结果与检验→含义和局限”的闭环；问题数量不固定为四问。
- 统一标题层级、正文、公式、图表注释、页码和参考文献；中文、英文、数字与数学字体在目标机器可用并嵌入。
- 全文查看渲染结果：缺字、溢出、大片空白、孤行、公式截断、错页码、图注跨页和表格小字。不要只检查代表页或文件能否打开。
- 正文引用图表和参考文献，数字、单位、指标口径与结果文件对齐。参考文献核验真实来源及链接，不用格式自检代替事实核验。
- 完整代码、数据说明和可重运行方法进入支撑材料；正文只保留解释模型所需的算法和关键推导，不堆运行日志。

paper_review.py 支持中文编号、Markdown、DOCX 和可提取文字的 PDF。文本解析不能测量页面高度、字体嵌入或图表遮挡；扫描 PDF 无文字时须转为视觉检查。页数、字数阈值仅在用户传入参数时启用。
