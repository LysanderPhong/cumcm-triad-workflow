# 论文版式与篇幅档案【单轮样本观察；目标规则未验证】

本档案来自三份用户提供的公开/历史样本与当前候选稿的只读对比。它提炼版式骨架，不复制任何样本的数字、句子、题面结论或独特图形。

## 样本事实

| 样本 | 页数 | 可观察特征 | 采用边界 |
|---|---:|---|---|
| 样本 A：烟幕干扰投放策略 | 40 | 中文大标题居中；正文中文衬线字体与 Times 风格英文混排；每问独立分析、建模、求解、检验；图注/表注编号清楚；参考文献和分问题代码附录齐全 | 吸收版式骨架；页数不作为目标，因超过 30 页 |
| 样本 B：碳化硅外延层红外干涉测厚 | 66 | 摘要按问题逐段给出方法、数值和不确定性；章节与附录很完整；公式、代码和校准材料较多 | 吸收结果表达和证据组织；不照搬篇幅，66 页超出目标 |
| 样本 C：起伏海底多波束测深 | 28 | 正文与图表密度平衡；问题拆分、模型、结果和测线方案衔接紧；篇幅落在目标区间 | 作为 20–30 页版式和密度的主要参考 |
| 当前候选稿 | 29 | 证据边界、假设和稳健性较强；正文叙述相对压缩，代码附录占比高，图表和参考文献层次仍可加强 | 作为待改对象，不把 29 页本身当作质量证明 |

上述页数由 PDF 元数据读取；字体和段落判断来自嵌入字体表、文本提取及代表页渲染。部分中文 PDF 在当前 Poppler 环境出现字体映射警告，因此字号只记录为相对层级，不宣称精确磅值。

## 默认版式合同

### 篇幅

- 目标总页数：约 25 页；允许区间 20–30 页，超出只产生 `REVIEW`，不自动删改科学内容。
- 正文优先保证问题分析、模型、求解、结果检验和模型评价完整；代码放支撑包或附录中的关键片段，不把整段运行日志堆进正文。
- 页数只能作为版式约束，不能用“凑够 25 页”替代推导、证据或解释。

### 页面骨架

1. 首页：居中题目、摘要、关键词和页码，摘要按子问题给出方法、关键结果、验证和限制。
2. 正文：问题背景/重述 → 问题分析 → 模型假设 → 符号与单位 → 分问题建模与求解 → 结果检验/敏感性 → 模型评价。
3. 每个子问题保持“任务 → 数学定义 → 方法 → 结果 → 现实含义”的闭环，避免把所有问题压成一个算法总览。
4. 末尾：参考文献、支撑材料清单和按问题组织的关键代码/伪代码；完整源码进入支撑包并在清单中可定位。

### 摘要密度

- 摘要必须在首页完成，不能跨页；首页的“摘要”标题、正文和关键词合计应占可用正文区域约 70%–80%，避免只占上半页或挤到页底。
- 默认建议至少约 700 个中文字符作为机械复核起点，但字符数只是提示，不替代渲染检查；英文、公式较多的题目可由人工按实际高度调整。
- 内容按“问题范围 → 每问方法 → 关键数值/区间 → 验证方式 → 适用边界”组织，不能用空泛背景凑高度，也不能为了填满首页重复正文。
- `paper_review.py` 会在可提取文字中估计摘要中文字符数；低于阈值会标记 `HIGH`，最终仍需人工查看 PDF 首页确认没有溢出。

### 字体、层级和留白

- 中文正文使用一种可嵌入的衬线字体，英文/数字使用与之协调的 Times 或 Latin Modern；标题使用同一字体族的粗体或明确的黑体层级。
- 题目最大，一级标题显著但克制，二级标题统一编号；不要在同一页混用多套标题样式。
- 正文保持稳定的行距、首行缩进和页边距；避免摘要页过度留白，也避免代码页小到不可读。
- 页眉只保留必要的章节信息；页脚居中页码，章节切换和附录起始清晰。

### 图表和语言

- 图/表统一编号、居中、短注释；表格优先使用横线和留白，减少竖线与装饰边框。
- 每题至少有一张能解释模型或结果的图/表，但数量由论证需要决定；不为凑页数堆图。
- 默认每个子问题至少准备一张方法/结构图，以及一张结果/检验图或表；若题目不适用，必须在决定卡中说明并给出替代证据。
- 摘要和结果段落具体写“对象、指标、数值/区间、验证方式、限制”，少用无证据的“显著、最优、完全、通用”。
- 允许使用“我们先定义……随后检验……”等自然叙述，但不能虚构实验经历或复制样本的独特表达。

## 进入论文门的检查

执行 `scripts/paper_review.py` 时，PDF 候选稿会读取页数；默认 20–30 页之外标记为 `REVIEW`。排版门还必须人工检查代表页、公式、表格、字体嵌入、灰度打印和附录可读性。当前“按样本骨架稳定生成 20–30 页论文”的机制为【未验证】，第三套题才能检验跨题型效果。

中文字体必须在目标机器实际嵌入并通过中文 PDF 冒烟渲染；出现缺字、空白页或 Poppler/阅读器映射异常时，排版门保持阻断。样本 C 的中文字体在部分提取环境出现映射警告，因此不能仅凭“PDF 能打开”判定字体合规。
