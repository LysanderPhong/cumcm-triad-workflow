# 图表视觉规范与表达选择【未验证】

这是一套统一的默认风格，目标是让图表清楚、克制、可复核，而不是用装饰制造“高级感”。当前仓库没有对全部题型和评审偏好做实测，使用者仍需检查打印版和灰度可读性。

## 统一视觉合同

- 使用低饱和、色盲友好的连续或分类色板；默认从 `templates/figure_style.json` 读取，不使用大红大绿作为主色。
- 统一字体族、字号层级和线宽；中文、英文、数字和公式分别指定可用字体，正文图表保持同一字体策略。
- 扁平风格：关闭阴影、3D、渐变、发光、厚重边框和无信息装饰；只保留表达数据所需的网格、误差带和标注。
- 用位置、长度、形状、线型和透明度共同编码，不能只靠颜色区分；关键差异必须在灰度或打印后仍可辨认。
- 标题说清问题，坐标轴写单位，图注说明数据源、统计口径、样本范围和图支持的论文主张。
- 每张图绑定真实输入、生成脚本、版本和结果文件；禁止从论文文字反向绘制“看起来正确”的图。

## 按表达目的选图

| 表达目的 | 首选图形 | 可补充图形 | 避免 |
|---|---|---|---|
| 变量关系 | 散点图+拟合/置信带、相关矩阵 | 分面图、二维密度 | 只用饼图或装饰性气泡 |
| 分布与异常 | 箱线图、小提琴图、ECDF | 直方图+密度 | 截断坐标轴掩盖差异 |
| 时间变化 | 折线图、置信带、事件标线 | 热力图、small multiples | 过多曲线挤在一张图 |
| 模型比较 | 点估计+区间、排序条形图 | slopegraph、森林图 | 3D 柱图、双轴误导 |
| 不确定性 | 区间带、误差棒、概率扇形 | bootstrap 分布 | 只报单点最佳值 |
| 优化/权衡 | Pareto 前沿、等高线 | 敏感性热力图 | 只标“最优”不展示约束 |
| 分类/混淆 | 归一化混淆矩阵、校准图 | ROC/PR（按任务适用） | 只报 accuracy |
| 空间/网络 | 分级色图、网络图 | 小 multiples | 彩虹色、无比例尺地图 |

图形数量由论证需要决定：一张图必须回答一个明确问题；如果两张图表达同一件事，保留更可读的一张。

## 自动检查边界

`templates/figure_style.json` 是生成器的默认配置。`paper_review.py` 会检查论文文本中的图表说明和可选 `figure_manifest.json` 的字体、色板、阴影/3D/渐变标记；这只能发现登记过的违规，不能替代实际渲染、打印和人工审阅。
