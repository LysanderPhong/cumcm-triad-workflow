# 图表与最终呈现检查

每张图回答一个明确问题；重复表达用图或表中更清楚的一种。数量由论证决定，不强制每问方法图和结果图。

- 变量关系用散点/拟合，时间变化用折线，分布用箱线/ECDF/直方图，比较用条形或点估计与区间；空间结构可以用真实 3D，热力图可以使用连续色阶。避免装饰性 3D、误导性的双轴和截断基线。
- 标明坐标名、单位、样本范围与统计口径。误差棒、区间带说明它代表标准差、置信区间还是其他范围；图注给出读者应得到的结论及必要限制。
- 类别同时使用线型、标记或直接标签；灰度打印后仍能区分。色板可选，不把固定低饱和配色当正确性标准。
- 在最终 PDF 的插入尺寸检查字号，建议轴与标注至少约 8–9 pt。绘图源文件的 9 pt 经缩放可能不足；不要只看源图。
- 优先矢量 PDF/SVG；栅格图按最终尺寸提供约 300 dpi，字体嵌入并检查中文、负号和公式。不要拉伸位图比例。
- 图、表、公式编号连续，正文有对应引用；表格对齐小数和单位，避免信息重复。页面内不遮挡、不过小、不把图注与图分开。
- 图来自真实结果与脚本；修正展示不改原始数据。确认图中的数值与正文及结果文件一致。

可选图表清单放在项目 `paper/figure_manifest.json`，所有文件引用相对于项目根目录：

```json
{"fonts":{"family":"实际使用的字体"},"figures":[{"path":"paper/figures/q1.png","input_refs":["results/metrics-v1.csv"],"script_ref":"code/plot.py","final_width_mm":150,"use_color_alone":false}]}
```

paper_review.py 可以检查登记的文件、来源和 PNG 插入分辨率。它不读取图形中的单位或遮挡，不认证色盲可读性，也不能从 JSON 声明证明实际字体正确；实际 PDF 的检查不可省略。
