## 论文格式：逐条核对

按[2026格式规范](https://www.mcm.edu.cn/html_cn/node/4cd596519c9eb9fbd866398f6df0caa3.html)定位条款，后列为本 Skill 采用的核验方式。

| 条款 | 官方要求摘要 | 核对证据/动作 |
|---|---|---|
| 第1条 | A4白纸，四边距≥2.5 cm，左侧装订 | 查页面尺寸/版心及纸质版 |
| 第2条 | 纸质前两页为承诺书、编号专页 | 纸质与电子分别组装 |
| 第3条 | 摘要含题目/关键词，原则一页；页脚中部从1连续编号 | 渲染首页和页码 |
| 第4条 | 不设目录，正文≤30页；后接不限页附录并合订 | 分开计正文/附录 |
| 第5条 | 附录列支撑文件及全部完整可运行源程序，含交互命令；未用程序则明示 | 审完整使用链、附录全文、重放结果 |
| 第6条 | 摘要、正文、附录不出现身份、学校、赛区信息 | 文本/元数据/可视页检查 |
| 第7条 | 引用公开或他人成果须列文献并在正文标注 | 引用与真实来源双向核对 |
| 第8条 | 字号、字体、行距、颜色无全国统一要求；赛区可补充 | 保存实际适用赛区通知 |
| 第9条 | 按报名参赛须知提交论文、支撑材料两个电子文件 | 核对当前系统和须知 |
| 第10条 | 电子论文与纸质内容格式一致；单文件PDF/Word≤20MB，不压缩；去掉前两专页 | 查大小/格式/摘要首页/附录 |
| 第11条 | 必要支撑含源码、自查数据等；RAR/ZIP≤20MB，清单入附录；全包匿名且无两专页；无支撑则说明 | 成员/依赖/清单/匿名逐项对账；按原文用WinRAR压缩要求核对实际交付 |
| 第12条 | 新规范优先，不符可能取消评奖资格 | 核对当年最新版本 |
| 第13条 | 解释权属组委会 | 解释未明确处不得自造官方豁免 |

“全部源码”不能缩成 `run_all.py` 等入口；至少沿实际使用的模型、几何核心、导入模块、图表/工作簿生成与辅助处理链检查。ZIP 内有代码不能替代附录全文。没有使用的条件路线与确实使用的辅助程序分开记录；存在解释不确定性时保留待核查，不由模板替官方放宽。这是由 B01 C1、B02 源码范围反复漏项导出的具体检查方法【两轮验证的必要性】，见 `benchmark_01/external_review/blind_review.md` 和 `benchmark_02/reviews/source_appendix_scope_decision_card_20260905.md`。

XeLaTeX、ctex、中文字体、双遍编译、缺字/溢出检查是本 Skill 的环境/质量实践，不是第8条强制技术栈。正文≤30页不等于总PDF≤30页。独立 References 标题有助于 AI 声明定位，但不能因本地提取器要求而编造引用。

## AI 使用：逐条核对

按[2026 AI试行规定](https://www.mcm.edu.cn/html_cn/node/fef94648f2836ab6cc81586f4c38512b.html)核对。

| 条款 | 官方要求摘要 | 核对证据/动作 |
|---|---|---|
| 第1条 | 覆盖大模型、生成式AI、代码辅助、AI智能体等 | 列实际工具，不能漏审查/排版代理 |
| 第2条 | 使用非强制；公开透明；参赛队主导核心建模分析并逐项人工审查核实 | 保存真实决定与核验事实，不自动代填 |
| 第3条 | 参考文献前设置AI工具使用声明，依实际使用二选一 | 采用官网相应声明模板，填真实简要用途 |
| 第4(1)条 | 工具名称、版本或型号 | 可证实则填写；未知处明示，不造构建号 |
| 第4(2)条 | 具体目的和环节 | 与实际使用记录对账 |
| 第4(3)条 | 主要提示方式和使用过程，可附典型交互 | 过程如实概述；例子是可选，不冒充逐字导出 |
| 第4(4)条 | 采纳、人工修改与核验情况；语言润色除外 | 定位真实人工核验，不由代理证明人类做过 |
| 第4条载体 | 支撑材料内含固定名“AI工具使用详情.pdf” | 查成品PDF和最终包成员 |
| 第5条 | 不合规按情节处理；隐瞒/虚假声明/未经必要人工核验直接提交核心AI成果取消评奖资格 | 缺事实保持阻断，不用自评替代 |
| 第6条 | 2026-09-01起试行，与旧规定冲突时以本规定为准 | 不沿用冲突的2025要求 |
| 第7条 | 组委会解释 | 不把内部审核当官方裁定 |

2026 第4(3)条把典型交互例子列为可附材料；没有强制提交全部聊天导出。保留关键交互有助于审查，是本 Skill 的证据实践，不能误说成 2026 新增的强制全文导出要求。AI 工具不因“使用过”就自动成为必须独立列在参考文献中的条目；具体引用公开成果仍按格式第7条处理。使用 [AI披露模板](../templates/ai_usage_disclosure.md) 时按真实事实替换，不直接提交占位符。

## 三角色在训练和正式竞赛中的边界

[参赛规则第5–6条](https://www.mcm.edu.cn/html_cn/node/9d8e511fe7a1447b35f53a82c908e2e0.html)禁止比赛期间与队外人员交流赛题，也禁止在交流平台浏览、发布或讨论相关内容，同时允许AI辅助并要求参赛队负责。

因此，历史训练可安排外部人工盲审；**正式比赛中的独立审核员应是同队成员或独立AI审核会话**，不能把队外真人导师、同学或公开问答者纳入题目审查。单人配置由参赛者决策与核验，执行AI和审核AI分开；AI审核不替代本人逐项核验。当前在赛前制作和公开 Skill 不等于获准比赛期间公开赛题/解答。【B02 三角色实践单轮验证；正式竞赛现场执行效果未验证】
