# 历史论文风格档案

这是论文门内的可选写作子阶段。目标是减少模板化表达，同时保留模型、数字、证据和人类决策的真实性；它不是“伪装 AI”或复制旧论文的机制。

## 进入条件

- 当前题目的问题定义、方法决定、结果文件和允许主张已经登记；
- 人类明确选择要做风格档案，而不是把风格改写误当成科学修复；
- 老论文来源可定位。优先使用全国大学生数学建模竞赛组委会或中国大学生在线公开展示页；第三方 PDF 只能作为补充，奖项等级必须另行核验。

## 风格特征抽取

每篇样本记录来源、实际查看页码和可信度，然后观察：

1. 摘要是否按“现实矛盾—建模任务—主要方法—核心结果—现实含义—边界”推进；
2. 每个分问是否先把题意改写成可计算对象，再定义变量、约束和评价指标；
3. 算法名称前是否解释了它要解决的现实问题；
4. 数值结果后是否说明它改变了哪个时点、分组、路线、调度或筛查动作；
5. 异常值、失败情形、误差、敏感性和适用范围是否被具体写出；
6. 语言层面是否存在可复核的差异，如句长分布、连接词、算法名密度、数字/单位密度和模态词使用。

“更有人味”“更自然”“更像老论文”不能直接作为特征，必须拆成上述可观察项目。

## 当前论文的受约束改写

风格改写只允许：

- 压缩重复句，调整段落顺序，补足已有证据支持的结果解释；
- 把作者已经作出的模型选择、阈值选择和取舍写得更清楚；
- 使用“在本样本内”“提示”“与……一致”等符合证据强度的表达；
- 让段落优先遵循“现象 → 量化定义 → 模型 → 证据 → 现实含义”。

风格改写禁止：

- 新增数据、实验、文献、模型、作者动机或因果结论；
- 复制历史论文的句子、段落结构或独特措辞；
- 把相关性写成因果性，把内部筛查指标写成临床诊断结论；
- 为了制造“人味”加入口语、反问、故意不规则的句子或未经验证的个人经历。

## 必留产物

在项目论文目录中保存：

- `style_profile.md`：样本来源、已观察特征、适用性判断和未验证项；
- `style_change_log.md`：原句、修改句、修改原因、是否改变科学含义；
- 受约束改写后的论文草稿，以及原有的结果、符号和人工决定引用。

风格档案完成不代表论文通过。仍须回到论文门，执行数字可追溯、主张边界、公式/符号一致、图表引用和独立审核。
